## 八、K线指纹: 命中(WR20) vs 未命中

## 九、综合推理

### 最可能达到WR20的信号特征(按重要性排序)

1. **推送后回撤浅** — 轻度回撤(<20%)的命中率71%，是极端回撤的4倍
2. **new_revival信号** — 比abnormal高14pp
3. **推送前涨幅温和** — <50%的命中率62%，>500%的只有44%
4. **推送时段晚** — 20-24h(UTC)的62% vs 08-12h的46%
5. **推送前有波动** — 波动190%的命中组 vs 141%的未命中组（死寂不利）
6. **市值适中** — <30K爆发强，100-300K最稳定

### 最可能失败的信号特征

1. **推送后重度回撤(>50%)** — 命中率仅42%
2. **abnormal信号** — 命中率45%
3. **推送前涨幅>500%** — 命中率44%
4. **大市值>300K** — 命中率39%
5. **周一推送** — 命中率46%

## 十三、关于"死寂区"的重要发现

在515个信号中，**只有1个信号的推送前最后12根5m bar的最大成交量<500美元**。这意味着:

- "死寂区"(长时间无人交易)在底部异动信号中**几乎不存在**
- 之前关于"死寂→爆发"模式的分析是基于少数极端案例(yunc, HENRY)，不具普适性
- **绝大多数成功信号在推送前都是活跃交易的**（有波动、有量）

**这推翻了之前的一个重要假设——"缩量横盘筑底"不是主流成功模式。主流模式是"活跃波动中的回踩反弹"。**

## 十四、1m K线指纹分析 (431信号)

**数据来源**: `bottom_kline_cache_1m`，每信号提取推送前60min+推送后120min的1m K线。

### 14.1 推送前最后30min

| 特征 | 命中组(n=232) | 未命中组(n=199) |
|------|-------------|-------------|
| 平均bar实体% | 5.02% | 4.66% |
| 量比(后半/前半) | 1.25x | 1.40x |
| 阳线比例 | 50% | 49% |
| 长下影出现次数 | 226 | 88 |

**命中组的1m bar实体更大(5.0% vs 4.7%)，量比更温和(1.25x vs 1.40x)。** 未命中组量比更高意味着推送前30分钟在放量，但这放量可能是恐慌抛售而非健康换手。

### 14.2 推送前最后5min

| 特征 | 命中组 | 未命中组 |
|------|--------|---------|
| 平均实体% | 4.62% | 4.32% |
| **5min总涨跌** | **+5.09%** | **+1.69%** |
| 阳线比例 | 53% | 53% |

**推送前5分钟内，命中组平均已涨5%，未命中组只涨1.7%。** 推送前已经在温和上涨的信号更容易成功。

### 14.3 推送后5min — 最关键的判定窗口

| 特征 | 命中组 | 未命中组 |
|------|--------|---------|
| **5min涨跌** | **+4.29%** | **-1.72%** |
| 平均成交量 | $1,354 | $730 |
| 5min涨>3%(抢筹) | **43%** | 23% |
| 5min横盘(-3~3%) | 22% | 34% |
| 5min跌<-3%(恐慌) | 35% | **43%** |

**这是最清晰的区分信号: 推送后5分钟内涨>3%的，43%最终达到WR20；跌<-3%的，只有35%能翻盘。** 5分钟涨跌是推送后最快可用的决策信号。

### 14.4 推送后30min — 决定性确认

| 特征 | 命中组 | 未命中组 |
|------|--------|---------|
| **30min涨跌** | **+15.42%** | **-2.90%** |
| 30min最低点 | -17.34% | -25.13% |
| 量趋势(30min/10min) | 1.18x | **1.51x** |

**30分钟后，命中组平均涨15%，未命中组跌3%。** 差距从5min的6pp扩大到30min的18pp——时间越久越确定。

**未命中组的量比更高(1.51x vs 1.18x)** — 因为未命中组在30分钟内持续放量下跌(恐慌抛售)，而命中组温和放量上涨。

### 14.5 1m+5m联合判定规则

```
推送后5min:
  涨>3% → 43% WR20 → 可考虑入场
  横盘 → 等30min确认
  跌<-3% → 35% WR20 → 大概率放弃

推送后30min:
  涨>0% → 确认上涨 → 加仓
  跌<0% → 大概率死亡 → 放弃
  量比>1.5x + 持续下跌 → 恐慌未结束 → 绝对不入
```

### 14.6 Bar序列模式

对推送前最后6根5m bar的涨跌+量能序列进行模式挖掘，**未发现统计上显著的高频模式**。每个序列模式的样本量都太小(n=1-8)，无法形成可靠的统计推断。bar序列模式不适合作为独立决策依据。
