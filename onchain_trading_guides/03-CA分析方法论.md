# CA分析方法论：从输入到结论的完整流程

> 记录分析一个异动CA时，每一步做了什么、为什么这样做、数据从哪来。

---

## 完整流程（6步）

```
用户输入CA地址
  │
  ├─ Step 1: 查推送记录（1秒）
  │    来源: bottom_top100_push_records
  │    拿到: 信号类型/市值/ATH/币龄/PoolRatio/涨幅
  │
  ├─ Step 2: 拉5m+1m K线（2-5秒）
  │    来源: bottom_kline_cache 或 Binance API
  │    计算: 推送价baseline / pre涨跌幅 / post峰谷 / 当前状态
  │
  ├─ Step 3: 逐bar分析（<1秒，纯计算）
  │    5m: 看大结构 — 横盘/暴跌/反弹/量能趋势
  │    1m: 看微观 — 最后5根是否缩量企稳？推送前是否有隐藏砸盘？
  │
  ├─ Step 4: 查历史同类（<1秒）
  │    来源: signal_kline_records.jsonl (515信号)
  │    筛选: 同信号类型 × 同回撤深度 × 同市值档位 × ATH比率
  │    拿到: 历史WR20基准
  │
  ├─ Step 5: 综合判定
  │    5个维度打分: 信号类型/回撤深度/ATH空间/1m确认/5m形态
  │
  └─ Step 6: 输出结论
       可入场 / 等确认 / 放弃 + 具体条件
```

---

## Step 1: 查推送记录

**SQL查询**:
```sql
SELECT symbol, signal_type, event_ts, current_mcap, ath_mcap,
       price_change_pct, liquidity, pool_mcap_ratio, age_sec
FROM bottom_top100_push_records
WHERE address = '<CA>'
ORDER BY event_ts DESC LIMIT 1
```

**拿到数据后立刻判断**:

| 字段 | 看什么 | 红线 |
|------|--------|------|
| signal_type | new_revival(59%WR20) > abnormal(45%) | — |
| current_mcap | $100-300K最优(69%) | <$30K高风险 |
| ath_mcap | ATH/当前>3x最好 | <1.5x天花板压制 |
| price_change_pct | 越低越好(<50%=62%WR20) | >500%信号滞后 |
| pool_mcap_ratio | — | 无绝对红线 |
| age_sec | 新币(<24h)更活跃 | >100天弹性差 |

## Step 2: 拉5m+1m K线

**API调用**（DB没有时）:
```
GET https://dquery.sintral.io/u-kline/v1/k-line/candles
  ?address=<CA>&platform=solana&interval=5min&limit=48
  ?address=<CA>&platform=solana&interval=1min&limit=60
```

**注意数据格式**: `[open, high, low, close, volume, ts_ms, trade_count]`

**计算核心指标**:
```python
baseline = 推送前最后一根5m bar的close  # 不是K线第一根!
pre_low = pre段最低价 / pre_high = pre段最高价
pre_pump_pct = (pre_high - pre_low) / pre_low   # 推送前涨了多少
pullback = (baseline - pre_high) / pre_high      # 推送时是否在回撤

post_peak = post段最高价 / post_trough = post段最低价
peak_pct = (post_peak - baseline) / baseline     # 最高涨了多少
trough_pct = (post_trough - baseline) / baseline # 最多跌了多少
cur_pct = (当前价 - baseline) / baseline         # 现在什么位置
recovery = (当前价 - post_trough) / post_trough  # 从底部弹了多少
```

**回撤区间判定**:
- trough > -20% → 轻度（历史71% WR20）
- -50% < trough ≤ -20% → 中度（46%）
- -80% < trough ≤ -50% → 重度（42%）
- trough ≤ -80% → 极端（40%）

## Step 3: 逐bar分析

### 3a: 5m K线 — 看大结构

**推送前最后12根5m bar，逐根看**:

| 找什么 | 怎么找 | 含义 |
|--------|--------|------|
| 横盘企稳 | 6根以上bar缩量窄幅(波动<15%) | 洗盘充分 ✅ |
| 暴跌后V反 | 一根-20%以上 + 一根+15%以上 | 可能死猫跳 🟡 |
| 持续阴跌 | 连续红bar+量不缩 | 卖压未结束 ❌ |
| 放量拉升 | 绿bar+量增>2x | 资金进场 ✅ |
| 缩量触底 | 红bar但量极小 | 卖压枯竭 ✅ |

**推送后所有bar，逐根看**:

| 找什么 | 怎么找 | 含义 |
|--------|--------|------|
| 第一根bar方向 | 涨/跌/平 | 涨→44%WR30, 跌→68%死透 |
| 巨阳确认 | 触底后出现>15%绿bar+量增>1.5x | V反确认 ✅ |
| 二次暴跌 | 反弹后出现更大的阴线 | 恢复失败 ❌ |

### 3b: 1m K线 — 看微观真相

**推送前最后10根1m bar**:

| 找什么 | 怎么找 | 含义 |
|--------|--------|------|
| 缩量企稳 | 最后5根量<$500, 波动<±3% | 充分洗盘 ✅ |
| 隐藏砸盘 | 倒数5-10根有放量砸盘(V>$2K, 跌>5%) | 5m看不出来 ❌ |
| 抢跑 | 最后2根突然放量拉升 | 可能在拉盘 🟡 |

**推送后1m**:

| 找什么 | 怎么找 | 含义 |
|--------|--------|------|
| 5min方向 | 涨>3% / 横盘 / 跌<-3% | 43% / 等 / 35% WR20 |
| 30min方向 | 涨>0% / 跌<0% | 60% / 30% WR20 |
| 30min量比 | >1.5x + 持续跌 | 恐慌抛售=放弃 |

## Step 4: 查历史同类

从 `data/deepseek_discovery/signal_kline_records.jsonl`（515信号）筛选匹配条件的信号：

```python
# 逐层筛选
g = [r for r in all_signals]
g = [r for r in g if r['signal_type'] == 当前CA的信号类型]    # 同信号
g = [r for r in g if 同回撤区间]                            # 同回撤深度
g = [r for r in g if 同市值档位]                            # 同市值
g = [r for r in g if 同ATH比率]                             # 同ATH空间

# 计算基准
wr20_baseline = sum(1 for r in g if r['outcome']['wr20']) / len(g)
```

**参考基准**（来自02文档 §1）:

| 条件 | 基准WR20 |
|------|---------|
| new_revival + $100-300K | 69% |
| new_revival + 轻度回撤 | ~75% |
| abnormal + 中度回撤 | ~40% |
| ATHx3-5 + 轻度回撤 | **83%** |

---

## Step 5: 综合判定

5个维度，每个给绿灯/黄灯/红灯:

| 维度 | 绿灯 | 黄灯 | 红灯 |
|------|------|------|------|
| 信号类型 | new_revival | — | abnormal |
| 回撤深度 | 轻度 | 中度 | 重度/极端 |
| ATH空间 | >3x | 2-3x | <1.5x |
| 1m确认 | 5min涨>3%+横盘 | 横盘 | 5min跌<-3% |
| 5m形态 | 横盘企稳+放量阳 | 震荡 | 持续阴跌/二次暴跌 |

- **4绿以上** → 正常仓位入场
- **3绿** → 轻仓试错
- **2绿以下** → 放弃

---

## Step 6: 输出结论

**可入场** → 给具体仓位和止损
**等确认** → 给具体条件（如"等>15%放量阳线"、"等5min横盘结束"）
**放弃** → 给具体理由（如"死透信号"、"ATH天花板"、"PoolRatio太高"）

---

## 总结：每次分析的固定流程

1. 查推送 → 2秒
2. 拉K线 → 5秒
3. 逐bar分析5m+1m → 1秒
4. 查历史同类 → <1秒
5. 5维判定 → 即判
6. 输出结论
