## 零、术语速查

| 术语 | 大白话解释 |
|------|-----------|
| **投降Bar** | 5分钟内暴跌超8%+成交量暴增3倍以上="有人扛不住了,不计成本砸盘清仓" |
| **放量阳线** | 5分钟内暴涨超8%+成交量暴增3倍以上="有大资金冲进去了" |
| **锤子线** | 长下影线(下影线是实体的3倍以上)="跌下去被人接住了,买方在托底" |
| **射击之星** | 长上影线(上影线是实体的3倍以上)="涨上去被人砸了,卖方在压盘" |
| **十字星** | 实体很小(<振幅的30%)+涨跌幅<3%="多空打了个平手,后面要选方向" |
| **缩量Bar** | 成交量不到前一根的30%="没人玩了,交易枯竭" |
| **pos(价格位置)** | 当前价格在过去4小时K线范围的什么位置: 0%=地板价, 100%=天花板价 |
| **PoolRatio(池比)** | 池子流动性÷市值。<25%=弹性好, 25-35%=正常, 35-45%=弹性受限, >45%=弹性差 |
| **前置模式** | 推送前48根5m K线的形态分类, 由本地聚类算法自动发现 |
| **后4h走势** | 推送后4小时内K线实际怎么走的 |
| **WR20** | 推送后4h内价格曾达到≥+20%的概率。**核心判断指标** |
| **WR50** | 推送后4h内价格曾达到≥+50% |
| **死透信号** | 推送后峰值<5%的信号, 107个, 占21% |
| **跌后涨(Drop-Pump)** | 推送后先跌>5%然后涨超30%的信号, 185个, 占36% |

### 1.8 ATH/当前市值比率 — 跌得越深，弹得越猛

**核心规律（515信号验证）:**

| ATH/MCap | n | WR20 | WR50 | AvgPeak |
|----------|-----|------|------|---------|
| 1-1.5x (接近ATH) | 86 | 55% | 30% | +46% |
| 1.5-2x | 74 | 42% | 18% | +47% |
| 2-3x | 107 | 50% | 30% | +100% |
| **3-5x** | **101** | **61%** | **37%** | **+112%** |
| 5x+ | 134 | 51% | 28% | +136% |

**ATHx3-5是最优区间(WR20=61%)。** 低于2x(接近ATH天花板)胜率下降。>5x的爆发力最强(+136%)但胜率回落。

**关键交叉: ATH深度 × 回撤深度**

| ATH/MCap | 轻度回撤 | 中度回撤 | 重度回撤 |
|----------|---------|---------|---------|
| 1-1.5x(接近ATH) | 59% | 55% | 50% |
| 2-3x | 68% | 38% | 45% |
| **3-5x** | **83%** | 61% | 41% |
| 5-10x | 64% | 41% | 33% |

**ATHx3-5 + 轻度回撤 = 83% WR20 (n=36)。** 这是全数据集胜率最高的组合之一。ATH跌得深 + 推送后不跌 = 几乎必胜。

**关于"横盘":** 纯缩量死寂(avg_body<5%)反而WR20只有35%。**需要的是"活跃的横盘"——有波动但不大跌，不是死寂无声。** 死寂代表无人关注，活跃代表资金在场。

**这是全数据集中区分生死的最强单指标。**

| 第一根5m bar方向 | DropPump(涨超30%) | Dead(死透) |

## 三、跌后涨超30%的K线走势 (185信号)

### 3.1 回撤深度分布

| 回撤深度 | 信号数 | AvgPeak | 判读 |
|---------|--------|---------|------|
| 浅跌(<10%) | 21 | **+323%** | 几乎不跌，爆发力最强 |
| 轻度(10-20%) | 49 | +131% | 小幅回踩后拉盘 |
| 中度(20-50%) | 62 | +84% | 最常见的恢复路径 |
| 重度(50-80%) | 44 | +83% | 深跌后暴力反弹 |
| 极端(>80%) | 9 | +132% | 跌透了弹得猛 |

**回撤越浅，爆发越强。** 浅跌<10%的AvgPeak=+323%, 是重度组的4倍。

### 3.2 恢复时间

| 指标 | 值 |
|------|-----|
| 到底中位时间 | 80分钟 |
| 从底部到峰值 | 5分钟(中位!) |
| 从底部平均反弹 | +347% |

**V反极快——底到顶中位仅5分钟。一旦确认底部, 必须立刻入场。**

### 3.3 四类K线模式

**类型A: 浅跌后爆发 (21个, WR20=90%)**

```
特征: 回撤<10%, 几乎不跌, AvgPeak=+323%
推送后表现: 第一根bar涨为主, 持续放量拉升
典型: F.03(-8%→+48%), 豆豆(-9%→+63%)
策略: 推送后5min涨>3%直接追
```

**类型B: 中度回撤后V反 (62个, 最常见)**

```
特征: 回撤20-50%, AvgPeak=+84%
推送后表现: 先跌到底(约80min), 触底后5-15分钟V反
第一根bar: 涨跌各半
典型: ALIEN(-32%→+166%), SPCX(-23%→+40%)
策略: 等触底+>15%放量阳线确认后入场
```

**类型C: 重度回撤后暴力反弹 (44个, 高风险)**

```
特征: 回撤50-80%, AvgPeak=+83%
推送后表现: 暴跌几乎归零, 然后暴力反弹
第一根bar: 跌为主
策略: 等缩量触底+>20%放量阳线, 试错仓位, 止损-15%
```

**类型D: 死透 (107个, 绝对放弃)**

```
特征: Peak<5%
推送后表现: 第一根bar 68%跌, 持续阴跌或横盘
Pre特征: 更死寂(bar实体9.5% vs 恢复组12.3%)
1m特征: 30min量比高(1.51x)=恐慌抛售
策略: 不碰
```

## 七、实战决策流程

```
推送发生 → 看推送后第一根5m bar
  │
  ├─ 涨>+1%
  │   └─ 等5min
  │       ├─ 涨>3% → 可入场(43% WR20)
  │       └─ 横盘 → 等30min确认
  │
  ├─ 跌<-1%  ← 68%是死透, 但要具体看
  │   └─ 等回撤深度确认
  │       ├─ 回撤<20% + 放量阳线 → 可能是类型A/B, 入场
  │       ├─ 回撤20-50% + 出现>15%阳线 → 类型B, 试错入场
  │       ├─ 回撤>50% + 缩量触底 → 类型C, 极轻仓+止损-15%
  │       └─ 30min量比>1.5x + 持续跌 → 死透, 放弃
  │
  └─ 30min后
      ├─ 涨>0% → 确认, 加仓(~60% WR20)
      └─ 跌<0% + 量比>1.5x → 放弃
```
