## 二、跌后涨超30%的K线走势

**定义**: 推送后最低跌幅>5%，且最终峰值≥+30%。共185个信号。

### 2.1 回撤深度分布

| 回撤深度 | 信号数 | AvgPeak | AvgTrough | 判读 |
|---------|--------|---------|-----------|------|
| 浅跌(<10%) | 21 | **+323%** | -8% | 几乎不跌，爆发力最强 |
| 轻度(10-20%) | 49 | +131% | -16% | 小幅回踩后拉盘 |
| 中度(20-50%) | 62 | +84% | -34% | 最常见的恢复路径 |
| 重度(50-80%) | 44 | +83% | -64% | 深跌后暴力反弹 |
| 极端(>80%) | 9 | +132% | -87% | 跌透了弹得猛 |

**关键是回撤越浅，爆发力越强。** 浅跌组AvgPeak=+323%，重度组只有+83%。

### 2.2 恢复时间

| 指标 | 值 |
|------|-----|
| 到底中位时间 | **80分钟** |
| 到顶中位时间 | **85分钟** |
| 从底部反弹幅度 | **+347%** |

**触底后到峰值平均只需5分钟。** V反非常快——一旦确认底部，立刻入场。

### 2.3 恢复路径 (典型案例)

```
SPCX: 跌-23%到底(195min) → 60min到顶+40% → 反弹+82%
ALIEN: 跌-32%到底(15min) → 120min到顶+166% → 反弹+291%  
F.03: 跌-8%到底(25min) → 115min到顶+48% → 反弹+61%
```

**两种恢复模式**:
- **快V**: 触底后5-15分钟内急速拉升(ALIEN, 15min到底→120min到顶)
- **慢V**: 触底后缓慢磨底再拉(SPCX, 195min到底→60min到顶)

## 七、三类K线走势总结

### 类型A: 浅跌后爆发 (21个, 最优)

```
特征: 回撤<10%, AvgPeak=+323%
推送后: 几乎不跌或微跌，立刻拉升
第一根bar: 涨为主
典型: F.03(-8%→+48%), 豆豆(-9%→+63%)
策略: 推送后5min涨>3%直接追
```

### 类型B: 中度回撤后反弹 (62个, 最常见)

```
特征: 回撤20-50%, AvgPeak=+84%
推送后: 先跌20-50%，触底后5-15分钟V反
第一根bar: 涨跌各半
典型: ALIEN(-32%→+166%), SPCX(-23%→+40%)
策略: 等触底+出现>15%放量阳线后入场
```

### 类型C: 重度回撤后暴力反弹 (44个, 高风险)

```
特征: 回撤50-80%, AvgPeak=+83%
推送后: 暴跌50-80%，几乎归零，然后暴力反弹
第一根bar: 跌为主
典型: 深跌后V反案例
策略: 等触底确认(缩量) + 出现>20%放量阳线，试错仓位
```

### 类型D: 死透 (107个, 放弃)

```
特征: Peak<5%
推送后: 第一根bar跌(68%), 持续阴跌或横盘
1m量比高(1.51x): 放量下跌=恐慌抛售
策略: 绝对不碰
```

## 八、实战决策流程

```
推送发生
  │
  ├─ 看推送后第一根5m bar
  │   ├─ 涨>1% → 44%概率涨超30% → 等5min确认
  │   └─ 跌<-1% → 68%是死透信号 → 谨慎
  │
  ├─ 等5min(1m数据)
  │   ├─ 涨>3% → 可入场(43% WR20)
  │   ├─ 横盘 → 等30min
  │   └─ 跌<-3% → 大概率死亡(35% WR20)
  │
  └─ 等30min确认
      ├─ 涨>0% → 确认，加仓(~60% WR20)
      ├─ 跌<0% + 量比>1.5x → 恐慌未结束，放弃
      └─ 跌<0% + 量比<1.0x → 卖压枯竭，可能是底部
```
